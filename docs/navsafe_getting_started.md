# Getting started with NavSafe

1. [Install](installation.md) the environment.
2. [Download data and evaluate](navsafe_eval.md) with your scenario token, model type and checkpoint.
3. For edited entries, [apply the matching frozen recipe](navsafe_eval_edited_scene.md).
4. Interpret status and success using [termination and scoring](navsafe_termination_and_success.md).

The public dataset contains 280 full-test bundles. Preserve its directory layout and point `NAVSAFE_DATA_ROOT` at the snapshot root. For authoring, see the [recipe editor](../navsafe/benchmark/editor/README.md).
