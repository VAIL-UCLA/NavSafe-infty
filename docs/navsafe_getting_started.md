# Getting started

1. [Install](installation.md) the environment.
2. [Download a scenario and evaluate a policy](navsafe_eval.md) on it.
3. For a scenario with a recipe, [run it edited](navsafe_eval_edited_scene.md).
4. [Run the full benchmark](navsafe_eval.md#full-benchmark-sweep) of 280 scenarios with one command.
5. Read the results with [scoring and termination](navsafe_termination_and_success.md).

The dataset keeps its directory layout on disk; point `NAVSAFE_DATA_ROOT` at its root. See [data layout](public-data-layout.md). To author scenarios, see the [recipe editor](../navsafe/benchmark/editor/README.md).
